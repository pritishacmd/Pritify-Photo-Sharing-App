# Pritify – Photo Sharing Application

**Pritify** is a photo-sharing application designed to provide users with a simple platform to upload, view, and manage photographs.

## Live Application

[Open Pritify](https://pritify-photo-flow.base44.app/)

## Key Features

- User registration and login
- Photo uploading and viewing
- Personal photo gallery
- Image processing
- Multi-resolution thumbnail generation (Small, Medium and Large)
- AI-assisted image moderation
- Email notifications after photo processing
- User profile management

## Application Workflow

1. The user logs into the application.
2. The user selects and uploads a photograph.
3. The application processes the uploaded image.
4. Multiple thumbnail resolutions are generated.
5. Image moderation is performed.
6. The user receives a processing notification.
